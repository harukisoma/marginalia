# Marginalia — 思考の余白

研究・勉強ノート、論文や本の読書記録、日記をつなぐ個人用Webアプリです。

公開先: https://harukisoma.github.io/marginalia/

## 使い方

- 左にページ一覧、中央にブロック文書、右にAIチャット。iPhoneでは画面を切り替えて使います。
- `/` または「＋」でブロックを追加。見出し1〜3、本文、リスト、チェックリスト、引用、表、画像、数式、コード、脚注、ページ埋め込みを使えます。
- 太字、斜体、取り消し線、下線、文字色、ハイライト、上付き・下付き文字に対応します。
- Markdownを貼り付けると文書へ変換します。「Markdown原文」で直接編集・反映でき、`.md` ファイルの読み込み・書き出しもできます。
- 数式は `$...$`、`$$...$$`、`\(...\)`、`\[...\]` で入力できます。数式をクリックするとTeXを編集できます。行列、複数行の式、AMS系の数式をMathJaxで描画します。
- コードは指定言語で色分けします。言語未指定の場合は自動判定します。
- `![[ページID]]`、または「ページ埋め込み」で他ページの本文を表示します。埋め込みから元のページへ移動できます。
- ページや文書はブラウザ内に自動保存します。初回オンライン訪問後はアプリ自体もキャッシュされ、オフラインで閲覧・編集できます。
- ゴミ箱から復元でき、設定画面から全体のバックアップを保存・読み込めます。

標準MarkdownとGFMの表・チェックリスト・取り消し線に加え、脚注、ハイライト、上下付き、数式、ページ埋め込みを扱います。複雑なHTMLは原文を保持する拡張ブロックになります。未知のMarkdown方言をすべて自動解釈するわけではありません。ブラウザで表示する数式用TeXを対象としており、LaTeX文書全体やTikZをコンパイルする機能ではありません。

## クラウド同期

このリポジトリには、本人のSupabaseプロジェクトのURLと **publishable key** を初期設定しています。このキーは公開可能なもので、ノートには本人のログインが必要です。秘密鍵・`service_role` キーはアプリやリポジトリへ入れません。

1. 公開アプリの「設定と接続」でメールアドレスを入力し、ログインリンクを送ります。
2. 同じブラウザでリンクを開きます。「クラウド同期済み」と表示されることを確認してください。
3. iPhoneでも同じメールアドレスでログインします。

Yjsが文書・ページごとの編集を管理し、IndexedDBへ保存します。再接続時はクラウドの状態を読み込んで統合し、版番号を確認して保存します。同時保存で版番号が変わった場合は読み直して再試行します。クラウド同期に失敗しても端末内の編集を残し、状態を表示します。別のログインアカウントへ既存ノートが送られないよう、同期アカウントを端末に関連付けます。

ブラウザのサイトデータ削除やプライベートブラウズは端末保存を消す場合があります。未同期の重要なノートは全体バックアップも保存してください。

別のSupabaseプロジェクトを使う場合:

1. SQL Editorで `supabase/schema.sql` と `supabase/relay.sql` を一度ずつ実行します。
2. Authentication → URL Configurationに公開アプリURLを設定します。MacでAIを使う場合は `http://127.0.0.1:4318/` も戻り先へ追加します。
3. アプリの「接続先の詳細」でProject URLとpublishable keyを指定します。

Realtimeは任意です。未設定でも定期取得と接続復帰で同期します。

## ChatGPTの契約を使う

OpenAI公式の **Sign in with ChatGPT** を使用します。APIキーの入力や従量課金APIへの自動切り替えはありません。利用できるモデルはログインしたアカウントから取得します。ChatGPTの契約・アプリごとの利用上限が適用されます。無制限を保証するものではありません。

OpenAIの公開クライアント認証は `127.0.0.1` のコールバックと保護されたローカル保存を使います。GitHub PagesのJavaScriptだけで認証情報を扱わず、Macの補助サーバーが認証とAIリクエストを担当します。

### Macで最初に接続する

Node.js 22以上が必要です。

```sh
npm ci
npm run build
npm run companion
```

1. `http://127.0.0.1:4318/` を開きます。
2. 設定画面の **Continue with ChatGPT** を押し、本人のChatGPTアカウントで認証します。
3. アプリに戻って「接続を確認」を押します。
4. GitHub Pages版で直接Macに接続する場合は、補助サーバー起動時の接続コードを設定します。ブラウザがローカルネットワーク接続の許可を求めることがあります。

認証情報は `.runtime/` に本人だけが読める権限で保存します。GitHub、ノート、ブラウザの保存領域へOpenAIのトークンを送信しません。再認証、トークン更新、切断を実装しています。

### iPhoneからAIを使う

1. Macのアプリでクラウド同期にもログインします。
2. 「このMacをiPhone用のAI接続端末にする」を押します。
3. iPhoneの公開アプリで同じ同期アカウントにログインします。

iPhoneの依頼は本人専用のクラウド領域に入り、Macが実行して応答を返します。**AIを使う間はMacが起動していて、補助サーバーが動いている必要があります。** Macが応答できない場合も、ノートの閲覧・編集・同期は使えます。依頼と応答は本人のクラウド領域に保存されます。OpenAIの認証情報はMacに残ります。

公開Webサービスとして他人に提供する場合は、Sign in with ChatGPTの提供条件を改めて確認してください。この実装は本人が管理するローカルAI実行環境を使う個人用ツールです。

### AIでできること

文章整理、推敲、TeX・コードの表記修正、要約、指定ページや日記を除いた全ノートを参照した回答を依頼できます。参照ページへのリンクと変更案を表示し、変更案ごとに採用・却下できます。承認前は本文を書き換えません。対象の文章が更新されたり複数箇所に存在したりする場合は、上書きせず再提案を促します。コード実行・外部Web検索など、未実装の操作を実行したとは表示しません。

- https://developers.openai.com/siwc/token-sharing-open-source/sign-in

## 開発と公開

```sh
npm run dev
npm test
npm run build
```

GitHub PagesのSourceをGitHub Actionsに設定します。`main` に変更を保存すると、テスト・ビルドを実行して公開します。ノート本文、ブラウザの保存データ、`.runtime/` は公開対象に含みません。

テストはOAuthのPKCE・state・client ID検証、AI変更対象の確認、通信中断と利用上限の処理、複雑な数式の変換、オフラインでの同時文書編集の統合を確認します。ログインを伴う実接続は本人の認証後に別途確認する必要があります。
